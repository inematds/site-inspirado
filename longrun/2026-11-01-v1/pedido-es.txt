<section id="resumo" class="resumo"><div class="wrap">
  <span class="chip">Em resumo</span>
  <p>O site-inspirado é um kit com uma skill para o Claude Code que cria sites que não têm cara de "feitos por IA". Você entrega imagens de referência (do Pinterest, do convite já impresso, da foto da loja) e a IA faz perguntas e pesquisa antes de gerar qualquer coisa. Depois ela mede o estilo dessas imagens, gera as imagens do site no mesmo estilo pelo Codex e monta a página com transições. No fim, um teste automático confere se o botão principal aparece e se a página funciona no celular. Para usar, você precisa do Claude Code, do Codex logado na sua assinatura, de Python e de Node.</p>
</div></section>

<section id="oque"><div class="wrap">
  <span class="chip">O que é</span>
  <h2>O processo é o diferencial, não o código</h2>
  <p class="sub">Pedir "faz um site bonito" dá o mesmo site de sempre. Dar referência, responder perguntas e conferir o resultado dá um site com cara própria.</p>
  <figure style="margin:0 0 26px;border-radius:16px;overflow:hidden;border:1px solid var(--line);box-shadow:0 30px 80px -30px #000"><img src="assets/banner-grade.jpg" alt="As seis etapas do site-inspirado: referências, perguntas, estilo medido, imagens no estilo, movimento e portão" loading="lazy" style="width:100%;display:block"></figure>
  <div class="grid g3">
    <div class="card"><h3>🎯 Pergunta antes de gerar</h3><p>Um roteiro de perguntas por tipo de site (evento, negócio, serviço, portfólio). O que a pessoa não respondeu é pesquisado ou fica de fora.</p></div>
    <div class="card"><h3>🖌️ Estilo medido</h3><p>O <code>estilo.py</code> tira a paleta das referências e calcula o contraste. Todas as imagens recebem o mesmo prompt de estilo e as mesmas referências.</p></div>
    <div class="card"><h3>✅ Portão antes de publicar</h3><p>O <code>portao.js</code> abre a página no computador e no celular e barra o site que esconde o botão, quebra ou ignora "reduzir movimento".</p></div>

  <h2>Seis etapas, uma conferência em cada</h2>
  <p class="sub">Nenhuma etapa começa sem a anterior aprovada. O guia abaixo tem 8 passos: instalar, estas 6 etapas (passos 2 a 7) e publicar. O "portão" é o teste automático do fim.</p>
  <div class="flow">
    <span>refs/</span><span class="arr">→</span>

  <span class="chip">Pré-requisitos</span>
  <h2>O que precisa estar instalado</h2>
  <p class="sub">Tudo roda na sua máquina. As imagens saem pelo Codex na sua assinatura, sem chave de API.</p>
  <div class="grid g3">
    <div class="card"><h3>Codex CLI logado</h3><p>Gera as imagens com o <code>image_gen</code> (o gerador de imagem do Codex), anexando as referências. O script roda o Codex sem pedir confirmação a cada imagem (<code>--dangerously-bypass-approvals-and-sandbox</code>): use numa pasta só do site.</p><pre><span class="k">npm i -g @openai/codex</span>   <span class="c"># instala</span>
<span class="k">codex login</span>              <span class="c"># entra com a conta do ChatGPT</span>
<span class="k">codex login status</span>       <span class="c"># confere</span></pre></div>
    <div class="card"><h3>Python 3 + Pillow</h3><p>Mede a paleta e monta a folha de contato.</p><pre><span class="k">python3 -m pip install --user pillow</span>
<span class="k">python3 -c</span> <span class="s">"import PIL"</span>  <span class="c"># confere</span></pre></div>
    <div class="card"><h3>Node 18+ e GitHub CLI</h3><p>O Node roda o portão (que abre a página num navegador sem janela, instalado no passo 1). O <code>gh</code> publica no passo 8.</p><pre><span class="k">node -v</span>             <span class="c"># 18 ou mais</span>
<span class="k">gh auth login</span>      <span class="c"># gh: cli.github.com</span></pre></div>

<section id="guia"><div class="wrap">
  <span class="chip">Guia de uso · passo a passo</span>
  <h2>Do zero ao site no ar</h2>
  <p class="sub"><code>T</code> é a pasta do seu site (uma por site). <code>S</code> é a pasta da skill. Os passos 3 e 6 você faz conversando com o Claude Code; os outros são comandos no terminal.</p>

  <div class="step"><div class="b">1</div><div>
    <h3>Instale a skill</h3>
    <p>Clone o repositório e ligue a skill ao Claude Code. <code>S</code> e <code>T</code> só valem no terminal em que você as criou: num terminal novo, rode a terceira linha de novo. Rode as linhas na pasta onde quer guardar o kit (o <code>ln -s</code> usa a pasta atual).</p>
<pre><span class="k">git clone https://github.com/inematds/site-inspirado</span>
<span class="k">mkdir -p ~/.claude/skills && ln -s "$PWD/site-inspirado/skill/site-inspirado" ~/.claude/skills/site-inspirado</span>
<span class="k">S=~/.claude/skills/site-inspirado; T=~/meu-site; mkdir -p $T/refs</span>
<span class="k">cd $S/scripts && npm install && npx playwright install chromium && cd -</span>  <span class="c"># navegador do portão</span></pre>
  </div></div>

  <div class="step"><div class="b">2</div><div>
    <h3>Junte as referências</h3>
    <p>De 2 a 5 imagens em <code>$T/refs/</code>: o que você já tem (convite, logo, foto da loja) e inspiração (no Pinterest, busque "site padaria" ou "wedding website watercolor"). Uma imagem do que você NÃO quer também ajuda.</p>
  </div></div>

  <div class="step"><div class="b">3</div><div>
    <h3>Deixe a IA perguntar primeiro</h3>
    <p>No Claude Code, abra a skill e diga a frase que muda o resultado. As perguntas por tipo de site estão em <code>referencias/perguntas.md</code>; as respostas vão para <code>$T/BRIEF.md</code>, junto com o tipo: <code>negocio</code> (o site existe para uma ação: encomendar, agendar) ou <code>visual</code> (evento, portfólio: pode ter mais movimento).</p>
<pre><span class="k">/site-inspirado</span> <span class="s">"Quero o site da minha padaria. Antes de gerar nada, me pergunte tudo o que precisa e pesquise o que um site deste tipo costuma ter."</span></pre>
  </div></div>

  <div class="step"><div class="b">4</div><div>
    <h3>Meça o estilo</h3>
    <p>O script mede a paleta das referências e sugere fundo, texto e destaque com o contraste calculado. O prompt de estilo descreve técnica, luz e cores.</p>
<pre><span class="k">python3 $S/scripts/estilo.py $T/refs $T/estilo.json --prompt</span> <span class="s">"honest food photography, warm window light, dark walnut, terracotta"</span>
<span class="c"># estilo.json: 12 cores · fundo #110a04 · tinta #ebdbce (14.55:1) · acento #b07042</span></pre>
  </div></div>

  <div class="step"><div class="b">5</div><div>
    <h3>Gere as imagens no mesmo estilo</h3>
    <p>Escreva <code>$T/plano.json</code> (uma linha por imagem: <code>nome</code>, <code>prompt</code> do assunto, <code>largura</code>, <code>altura</code>). Cada imagem leva as referências e a primeira imagem gerada como modelo (a "âncora"), para a série sair com a mesma mão. No fim sai a <code>folha.jpg</code>, uma folha com todas as imagens lado a lado: olhe e refaça o que destoar. Não precisa escrever o JSON à mão: peça ao Claude Code "escreva o plano.json a partir do BRIEF" ou copie <code>pilotos/padaria/plano.json</code> e troque os textos. Cada imagem leva cerca de 1 minuto e usa a cota da sua assinatura do Codex.</p>
<pre><span class="c"># plano.json: [{"nome": "hero", "prompt": "pães esfriando na mesa", "largura": 1536, "altura": 1024}, ...]</span>
<span class="k">python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs</span>
<span class="k">python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs --so croissant</span>  <span class="c"># refaz uma</span></pre>
  </div></div>

  <div class="step"><div class="b">6</div><div>
    <h3>Monte a página com movimento</h3>
    <p>Peça ao Claude Code: "monte a página com o BRIEF, o estilo e as imagens". Ele desenha uma página para o assunto e marca o botão principal (o CTA, a ação que você quer que o visitante faça) com <code>data-cta</code>. As transições vêm do <code>movimento.js</code>, por atributo: <code>data-revela</code> faz o bloco entrar ao aparecer na tela, <code>data-parallax</code> faz a imagem andar mais devagar que a rolagem, <code>data-intro</code> é uma abertura curta, <code>data-conta</code> conta um número e <code>data-contagem</code> mostra os dias até uma data. Tudo para quando o sistema pede "reduzir movimento". Copie o <code>movimento.js</code> para a pasta do site antes do portão:</p>
<pre><span class="k">&lt;section data-revela="cortina"&gt;</span> <span class="c">… sobe | surge | lado | zoom | cortina</span>
<span class="k">&lt;img data-parallax="0.12"&gt;</span>  <span class="k">&lt;b data-conta="36"&gt;</span>  <span class="k">&lt;div data-intro="900"&gt;</span>
<span class="k">&lt;a data-cta href="#encomendar"&gt;</span>Encomendar<span class="k">&lt;/a&gt;</span>
<span class="k">&lt;script src="movimento.js"&gt;&lt;/script&gt;</span>
<span class="k">cp $S/runtime/movimento.js $T/</span></pre>
  </div></div>

  <div class="step"><div class="b">7</div><div>
    <h3>Passe no portão</h3>
    <p>Abre a página em 1440×900 e 390×844, com e sem "reduzir movimento". Use o <code>--tipo</code> que está no BRIEF (<code>negocio</code> ou <code>visual</code>). Se sair <code>NÃO PASSA</code>, a lista diz o motivo: cole no Claude Code e peça a correção. Só publique com <code>PASSA</code>.</p>
<pre><span class="k">node $S/scripts/portao.js $T/index.html --tipo negocio --fotos $T/fotos</span>
<span class="c"># portão visual × conversão — meu-site (negocio)</span>
<span class="c">#   desktop          CTA na 1ª tela: sim · CTAs: 3 · peso 0.22 MB · erros 0</span>
<span class="c">#   celular          CTA na 1ª tela: sim · CTAs: 3 · peso 0.55 MB · erros 0</span>
<span class="c">#   desktop+reduzir  … · celular+reduzir  …</span>
<span class="c"># PASSA</span></pre>
  </div></div>

  <div class="step"><div class="b">8</div><div>
    <h3>Publique</h3>

Em resumo

O site-inspirado é um kit com uma skill para o Claude Code que cria sites que não têm cara de "feitos por IA". Você entrega imagens de referência (do Pinterest, do convite já impresso, da foto da loja) e a IA faz perguntas e pesquisa antes de gerar qualquer coisa. Depois ela mede o estilo dessas imagens, gera as imagens do site no mesmo estilo pelo Codex e monta a página com transições. No fim, um teste automático confere se o botão principal aparece e se a página funciona no celular. Para usar, você precisa do Claude Code, do Codex logado na sua assinatura, de Python e de Node.

O que é

O processo é o diferencial, não o código

Pedir "faz um site bonito" dá o mesmo site de sempre. Dar referência, responder perguntas e conferir o resultado dá um site com cara própria.

🎯 Pergunta antes de gerar

Um roteiro de perguntas por tipo de site (evento, negócio, serviço, portfólio). O que a pessoa não respondeu é pesquisado ou fica de fora.

🖌️ Estilo medido

O estilo.py tira a paleta das referências e calcula o contraste. Todas as imagens recebem o mesmo prompt de estilo e as mesmas referências.

✅ Portão antes de publicar

O portao.js abre a página no computador e no celular e barra o site que esconde o botão, quebra ou ignora "reduzir movimento".

Como funciona

Seis passos, um portão em cada

Nenhum passo começa sem o anterior aprovado. Os nomes de arquivo são os que o kit usa.

refs/→ BRIEF.md→ estilo.json→ img/ + folha.jpg→ index.html→ portão: PASSA
Pré-requisitos

O que precisa estar instalado

Tudo roda na sua máquina. As imagens saem pelo Codex na sua assinatura, sem chave de API.

Codex CLI logado

Gera as imagens com image_gen, anexando as referências.

# confira
codex login status

Python 3 + Pillow

Mede a paleta e monta a folha de contato.

python3 -c "import PIL"

Node + Playwright

Só o portão usa (navegador sem janela).

cd skill/site-inspirado/scripts
npm install && npx playwright install chromium
Guia de uso · passo a passo

Do zero ao site no ar

T é a pasta do seu site (uma por site). S é a pasta da skill.

1

Instale a skill

Clone o repositório e ligue a skill ao Claude Code.

git clone https://github.com/inematds/site-inspirado
ln -s "$PWD/site-inspirado/skill/site-inspirado" ~/.claude/skills/site-inspirado
S=~/.claude/skills/site-inspirado; T=~/meu-site; mkdir -p $T/refs
2

Junte as referências

De 2 a 5 imagens em $T/refs/: o que você já tem (convite, logo, foto da loja) e inspiração (no Pinterest, busque "site padaria" ou "wedding website watercolor"). Uma imagem do que você NÃO quer também ajuda.

3

Deixe a IA perguntar primeiro

No Claude Code, abra a skill e diga a frase que muda o resultado. As perguntas por tipo de site estão em referencias/perguntas.md; as respostas vão para $T/BRIEF.md, junto com o tipo: negocio ou visual.

/site-inspirado "Quero o site da minha padaria. Antes de gerar nada, me pergunte tudo o que precisa e pesquise o que um site deste tipo costuma ter."
4

Meça o estilo

O script mede a paleta das referências e sugere fundo, texto e destaque com o contraste calculado. O prompt de estilo descreve técnica, luz e cores.

python3 $S/scripts/estilo.py $T/refs $T/estilo.json --prompt "honest food photography, warm window light, dark walnut, terracotta"
# estilo.json: 12 cores · fundo #110a04 · tinta #ebdbce (14.55:1) · acento #b07042
5

Gere as imagens no mesmo estilo

Escreva $T/plano.json (uma linha por imagem: nome, prompt do assunto, largura, altura). Cada imagem leva as referências e a primeira imagem gerada como âncora. Depois, abra a folha.jpg e refaça o que destoar.

python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs
python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs --so festa  # refaz uma
6

Monte a página com movimento

Uma página desenhada para o assunto. O movimento.js dá as transições por atributo e para tudo quando o sistema pede "reduzir movimento". O botão principal leva data-cta.

<section data-revela="cortina"> … sobe | surge | lado | zoom | cortina
<img data-parallax="0.12">  <b data-conta="36">  <div data-intro="900">
<a data-cta href="#encomendar">Encomendar</a>
<script src="movimento.js"></script>
7

Passe no portão

Abre a página em 1440×900 e 390×844, com e sem "reduzir movimento". Só publique com PASSA.

node $S/scripts/portao.js $T/index.html --tipo negocio --fotos $T/fotos
#   desktop   CTA na 1ª tela: sim · CTAs: 3 · erros 0
#   celular   CTA na 1ª tela: sim · CTAs: 3 · erros 0
# PASSA
8

Publique

Copie o movimento.js para a pasta do site e publique como site estático (GitHub Pages, Vercel ou a hospedagem do cliente).

cp $S/runtime/movimento.js $T/ && cd $T && git init && git add -A && git commit -m "site"

Visual × conversão

Bonito demais também atrapalha

Um site existe para alguém fazer alguma coisa. O tipo no BRIEF decide quanto movimento cabe, e o portão mede.

🧁 Negócio

Botão na 1ª tela em até 1,5 s, sem abertura, barra fixa no celular, até 3 MB.

# padaria
PASSA

💐 Visual

Abertura de até 1,2 s, cortina, parallax e contagem; o botão pode vir depois, mas tem de aparecer. Até 8 MB.

# evento
PASSA

🚫 Página "imersiva"

Abertura que ocupa uma tela e meia, botão lá embaixo e animação infinita. É o teste tests/ruim.html.

# ruim.html
NÃO PASSA: CTA fora da primeira tela
animação rodando com "reduzir movimento"

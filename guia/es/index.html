En resumen

site-inspirado es un kit con una skill para Claude Code que crea sitios que no parecen «hechos por IA». Entregas imágenes de referencia (de Pinterest, de una invitación impresa o de una foto del local) y la IA hace preguntas e investiga antes de generar cualquier cosa. Después mide el estilo de esas imágenes, genera las imágenes del sitio con el mismo estilo mediante Codex y arma la página con transiciones. Al final, una prueba automática comprueba si aparece el botón principal y si la página funciona en el celular. Para usarlo, necesitas Claude Code, Codex con tu cuenta iniciada, Python y Node.

Qué es

La diferencia está en el proceso, no en el código

Pedir «haz un sitio bonito» da siempre el mismo sitio de siempre. Dar referencias, responder preguntas y revisar el resultado da como resultado un sitio con estilo propio.

🎯 Pregunta antes de generar

Una guía de preguntas según el tipo de sitio (evento, negocio, servicio, portafolio). Lo que la persona no responda se investiga o se deja fuera.

🖌️ Estilo medido

estilo.py extrae la paleta de las referencias y calcula el contraste. Todas las imágenes reciben el mismo prompt de estilo y las mismas referencias.

✅ Puerta de control antes de publicar

portao.js abre la página en la computadora y en el celular, y bloquea el sitio si oculta el botón, falla o ignora la opción «reducir movimiento».

Cómo funciona

Seis etapas, una revisión en cada una

Ninguna etapa empieza sin que se apruebe la anterior. La guía de abajo tiene 8 pasos: instalar, estas 6 etapas (pasos 2 a 7) y publicar. La «puerta de control» es la prueba automática del final.

refs/→ BRIEF.md→ estilo.json→ img/ + hoja.jpg→ index.html→ puerta: PASA
Requisitos previos

Qué necesitas tener instalado

Todo se ejecuta en tu computadora. Las imágenes se generan con Codex usando tu suscripción, sin clave de API.

Codex CLI con sesión iniciada

Genera las imágenes con image_gen (el generador de imágenes de Codex), adjuntando las referencias. El script ejecuta Codex sin pedir confirmación para cada imagen (--dangerously-bypass-approvals-and-sandbox): úsalo en una carpeta exclusiva para el sitio.

npm i -g @openai/codex   # instala
codex login              # inicia sesión con tu cuenta de ChatGPT
codex login status       # comprueba

Python 3 + Pillow

Mide la paleta y crea la hoja de contacto.

python3 -m pip install --user pillow
python3 -c "import PIL"  # comprueba

Node 18+ y GitHub CLI

Node ejecuta la puerta de control (que abre la página en un navegador sin ventana, instalado en el paso 1). gh publica en el paso 8.

node -v             # 18 o superior
gh auth login      # gh: cli.github.com
Guía de uso · paso a paso

De cero a un sitio publicado

T es la carpeta de tu sitio (una por sitio). S es la carpeta de la skill. Los pasos 3 y 6 los haces conversando con Claude Code; los demás son comandos en la terminal.

1

Instala la skill

Clona el repositorio y conecta la skill a Claude Code. S y T solo tienen validez en la terminal donde las creaste: en una terminal nueva, vuelve a ejecutar la tercera línea. Ejecuta las líneas en la carpeta donde quieres guardar el kit (ln -s usa la carpeta actual).

git clone https://github.com/inematds/site-inspirado
mkdir -p ~/.claude/skills && ln -s "$PWD/site-inspirado/skill/site-inspirado" ~/.claude/skills/site-inspirado
S=~/.claude/skills/site-inspirado; T=~/mi-sitio; mkdir -p $T/refs
cd $S/scripts && npm install && npx playwright install chromium && cd -  # navegador de la puerta de control
2

Reúne las referencias

De 2 a 5 imágenes en $T/refs/: lo que ya tienes (invitación, logo, foto del local) e inspiración (en Pinterest, busca «sitio panadería» o «wedding website watercolor»). También ayuda una imagen de lo que NO quieres.

3

Deja que la IA pregunte primero

En Claude Code, abre la skill y di la frase que cambia el resultado. Las preguntas según el tipo de sitio están en referencias/perguntas.md; las respuestas van a $T/BRIEF.md, junto con el tipo: negocio (el sitio existe para que alguien realice una acción: hacer un pedido, agendar una cita) o visual (evento, portafolio: puede tener más movimiento).

/site-inspirado "Quiero el sitio de mi panadería. Antes de generar nada, pregúntame todo lo que necesites e investiga qué suele tener un sitio de este tipo."
4

Mide el estilo

El script mide la paleta de las referencias y sugiere el fondo, el texto y los colores de énfasis según el contraste calculado. El prompt de estilo describe la técnica, la luz y los colores.

python3 $S/scripts/estilo.py $T/refs $T/estilo.json --prompt "honest food photography, warm window light, dark walnut, terracotta"
# estilo.json: 12 colores · fondo #110a04 · tinta #ebdbce (14.55:1) · acento #b07042
5

Genera las imágenes con el mismo estilo

Escribe $T/plano.json (una línea por imagen: nome, prompt del tema, largura, altura). Cada imagen lleva las referencias y la primera imagen generada como modelo (el «ancla») para que toda la serie mantenga el mismo estilo. Al final se crea folha.jpg, una hoja con todas las imágenes una al lado de la otra: revísala y vuelve a generar las que desentonen. No necesitas escribir el JSON a mano: pídele a Claude Code «escribe el plano.json a partir del BRIEF» o copia pilotos/padaria/plano.json y cambia los textos. Cada imagen tarda alrededor de 1 minuto y consume la cuota de tu suscripción de Codex.

# plano.json: [{"nome": "hero", "prompt": "panes enfriándose sobre la mesa", "largura": 1536, "altura": 1024}, ...]
python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs
python3 $S/scripts/imagens.py $T/plano.json $T/estilo.json $T/img --refs $T/refs --so croissant  # vuelve a generar una
6

Arma la página con movimiento

Pídele a Claude Code: «arma la página con el BRIEF, el estilo y las imágenes». Diseña una página para el tema y marca el botón principal (el CTA, la acción que quieres que realice el visitante) con data-cta. Las transiciones vienen de movimento.js y se activan mediante atributos: data-revela hace que el bloque aparezca en pantalla, data-parallax hace que la imagen se mueva más lento que el desplazamiento, data-intro crea una breve apertura, data-conta cuenta un número y data-contagem muestra los días que faltan para una fecha. Todo se detiene cuando el sistema solicita «reducir movimiento». Copia movimento.js a la carpeta del sitio antes de pasar la puerta de control:

<section data-revela="cortina"> … sube | aparece | lado | zoom | cortina
<img data-parallax="0.12">  <b data-conta="36">  <div data-intro="900">
<a data-cta href="#encomendar">Hacer un pedido</a>
<script src="movimento.js"></script>
cp $S/runtime/movimento.js $T/
7

Pasa la puerta de control

Abre la página a 1440×900 y 390×844, con y sin la opción «reducir movimiento». Usa el --tipo que aparece en el BRIEF (negocio o visual). Si aparece NO PASA, la lista indica el motivo: pégala en Claude Code y pide que lo corrija. Publica solo si aparece PASA.

node $S/scripts/portao.js $T/index.html --tipo negocio --fotos $T/fotos
# puerta visual × conversión — mi-sitio (negocio)
#   escritorio          CTA en la 1.ª pantalla: sí · CTA: 3 · peso 0.22 MB · errores 0
#   celular              CTA en la 1.ª pantalla: sí · CTA: 3 · peso 0.55 MB · errores 0
#   escritorio+reducir … · celular+reducir …
# PASA
8

Publica

La carpeta $T ya es un sitio estático completo. Súbela a GitHub y activa GitHub Pages, el alojamiento gratuito de páginas de GitHub (o usa Vercel o el alojamiento del cliente). Cambia SEU_USUARIO por tu usuario de GitHub.

cd $T && git init -b main && git add -A && git commit -m "site"
gh repo create meu-site --public --source=. --push
gh api -X POST repos/SEU_USUARIO/meu-site/pages -f "source[branch]=main" -f "source[path]=/"

Visual × conversión

Demasiada belleza también puede estorbar

Un sitio existe para que alguien haga algo. El tipo en el BRIEF determina cuánto movimiento puede tener, y la puerta de control lo mide.

🧁 Negocio

Botón en la primera pantalla en hasta 1,5 s, sin apertura, barra fija en el celular y hasta 3 MB.

# panadería
PASA

💐 Visual

Apertura de hasta 1,2 s, cortina, parallax y cuenta regresiva; el botón puede aparecer después, pero debe verse. Hasta 8 MB.

# evento
PASA

🚫 Página «inmersiva»

Apertura que ocupa una pantalla y media, botón hasta abajo y animación infinita. Es la prueba tests/ruim.html.

# ruim.html
NO PASA: CTA fuera de la primera pantalla
animación activa con «reducir movimiento»
